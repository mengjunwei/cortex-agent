Filesystem sandboxing defines which files can be read or written. `sandbox_mode` is `workspace-write`: The sandbox permits reading files, and editing files in `cwd` and `writable_roots`. Editing files in other directories requires approval. Network access is {{ network_access }}.
Inside the sandbox, `$TMPDIR` and `$HOME` are already redirected to writable per-session directories; the rest of the filesystem is read-only. Write generated files under `cwd`; use `$TMPDIR`/`$HOME` for tool scratch, lock, pipe and config files. When a command fails with `Read-only file system` or similar, it means the target path is outside these writable locations — do not retry variations blindly; write to a writable location instead.
